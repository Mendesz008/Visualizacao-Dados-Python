# Visualizacao-Dados-Python
Exercícios práticos de visualização de dados com Python, incluindo gráficos de linha, dispersão, barras e análise da Taxa Selic e do IPCA.
## O que foi desenvolvido
No notebook, explorei o uso prático das bibliotecas **Matplotlib**, **Seaborn** e **NumPy**. Durante o exercício, coloquei em prática:

* **Criação de gráficos:** Plots de linhas simples representando funções de seno e cosseno.
* **Estilização:** Aplicação de temas visuais nos gráficos, como o estilo `classic`.
* **Exportação de arquivos:** Como salvar os gráficos gerados via código (`plt.savefig`) configurando alta resolução (DPI) e fundo transparente.
* **Conceitos teóricos:** Estudo sobre o **Quarteto de Anscombe**, entendendo a importância de visualizar os dados graficamente em vez de confiar apenas em estatísticas puras.
